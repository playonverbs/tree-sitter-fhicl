# tree-sitter-fhicl

This repository intends to provide a tree-sitter grammar and generated language
bindings for the Fermilab Hierarchical Configuration Language (FHiCL).

> [!WARNING]
> This is a work-in-progress: currently missing parsing real-world files and
> all current test cases are not passing.
>
> In addition no direct comparisons to the `fhiclcpp` parsing codebase are made
> due to the inherent difficulties in generating builds independent of FNAL
> infrastructure.
